# Deduplication and exclusions

This is a documented finite comparison, not a claim that the exact source code of every broad public campaign has been audited.

## Removed before counting

- Four extra stream drafts (Geffe, feedback-with-carry, de Bruijn, Blum–Blum–Shub) duplicated the structural contributor's mechanisms. Counted only once there.
- Pure multiset-preserving versions of routing/word transforms cannot evade H-PERM. Only their explicitly fixed nonzero symbol-layer composites remain proposals; that layer is frozen, not a post-result rescue. The composite still needs comparison against earlier combined transposition/substitution scopes.
- Adaptive tournament **row-sum** scoring telescopes to endpoint imbalance. That draft was rejected; the retained model counts positive outgoing edges and requires a distinguishing-history witness.
- Eight proposed physical/archive leads were rejected or merged, not counted. See EVIDENCE-REJECTIONS.json. Hand-layout irregularities are not a new clue or an independently specified cipher.
- The bounded four-component Ducci stream is analytically zero by step 20 for every allowed seed. It is rejected and not among the 100; see REJECTED-DUCCI.json. No seed scan should run.

## Distinctions that need exact witness tests

| Candidates | Exact proposed distinction | Admission caveat |
|---|---|---|
| Adaptive transition-count bank / earlier-section bank | Online counts change after every recovered symbol; earlier-section counts remain fixed and independently sourced. | A sparse fixed bank may collapse to a simpler old operator; prove a witness before target use. |
| Earlier-section next-occurrence cursor / move-to-front | A cyclic external reference cursor advances to the next occurrence, rather than moving a decoded symbol in a mutable list. | Compare exact transition/output relations, not names or prose. |
| Algebraic rotor state / spatial rotor routing / sandpile-tree coding | Alphabet-state generation, ciphertext-determined source-position selection, and a bijection on encoded spanning trees act on different domains. | Check induced operators, fixed-route degeneracies and finite-state conjugacies. |
| Multiset rank / equality-partition rank | One preserves all letter multiplicities; the other preserves first-occurrence order and distinct-letter count while changing multiplicities. | Their rank arithmetic is not the novelty; the different constrained message spaces are. |
| RSK evacuation / alphabet-tableau promotion | One transforms the recording tableau of the full message; the other updates a 26-symbol alphabet state after each output. | Classical tableau operations are not new inventions. |
| Shrinking / self-shrinking / stop-and-go / majority clock / filtered register | Different selector/data dependencies and state-update timing. | Enumerate tiny exact stream sets to expose aliases; established generator names alone do not prove K4 novelty. |
| CRT representation code / CRT control mechanisms / shared-control solver | A reversible block representation, a cipher state transition, and an exact solver decomposition are different research claims. | Changing coordinates alone is not a new cipher; check conjugacy and prior containment. |
| M11 model-edit fragility / M22 observation-channel decoding | M11 fixes all ciphertext and edits the model; M22 holds the model and permits a frozen synthetic corruption channel. | M22 cannot license editing actual K4 or rescuing an eliminated model. |
| M01 semantic equivalence / M05 distinguishing suites / M13 source extraction | Proof of bounded operator equivalence, optimized fault-detecting inputs, and exact equation extraction have different measured outputs. | All are established methods; require the promised bottleneck gain rather than generic engineering claims. |
