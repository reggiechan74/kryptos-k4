## Measured design choice and future gate

A synthetic independent union solve took about 0.079 CPU seconds, justifying 872 fresh full-union benchmark cases under a 180-second batch cap. Every route-generating description is planted in uniform and literal-clue form with a fixed balanced period allocation; all 3,104 route/period descriptions were separately checked before freeze. This avoids an unmeasured extravagant benchmark while preserving complete-set comparison and deliberate ambiguity tests.

Only a measured bottleneck in a separately eligible hypothesis would justify a new solver or scorer. Preserve frozen code/gates; do not change the cursor convention, step rule, emission-key indexing, direction or reset behavior after seeing K4. These reusable exact-checking methods are established techniques, not globally new cryptanalytic inventions.

A specific future improvement suggested by the transcription error is read-only AST/literal extraction from pinned sources, coupled to source hashes and expected cardinality checks. Do not import or execute untrusted external modules. This extractor is only proposed, not implemented in study 062. Before reuse, independently validate it on fresh tiny source fixtures containing direction reversals, aliases and unsupported expressions; fail closed rather than silently guessing dynamic values. The actual remedy used here was corrected transcription plus independent primary-source verification, not an unbuilt automation claim.

## Measured held-out lesson

The sealed controls actually produced 120 ambiguous/free cases among 776 full-mask plants, while all true keys remained included. Thus the ambiguity safeguard was necessary, not merely theoretical. The other 656 full-mask plants recovered uniquely; all 32 deliberately sparse planted settings retained seven free residues. Do not reject correct implementations for failing an unjustified uniqueness gate or rank an arbitrary completion as the recovered message.

Production used about 13.025 inclusive CPU seconds and the independent reference 40.518 for 872 complete-union solves. Analysis checked 85,924 roundtrip probes in 5.215 seconds. No resource bottleneck justified changing this exact solver; keeping independent implementations is more useful than premature optimization.
