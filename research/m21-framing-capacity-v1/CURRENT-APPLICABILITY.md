# Current applicability — M21 after the synthetic checkpoint

## 1 November 2026: C02 capacity limitation

The original [applicability table](NEXT-APPLICABILITY.md) is preserved as the proposal-stage assessment. A later source/proof audit found that M21 supplies **no incremental capacity rejection for the direct C02 inverse candidates**: a fixed 97-digit positional base-26 representation already guarantees its integer is below `26^97`. Rechecking that same width bound with M21 cannot add a discriminator.

This does **not** exclude C02's fixed Huffman/framing model and does not show M21 useless in every domain. It means no cost-justified M21 K4 application has been established here. No M21 target count is admitted. The accepted source/proof audit specifies tree/tie/framing semantics and bounded prior art; independent implementation and finite validation/utility gates remain. No C02 experiment is authorized by this note.

The [completed synthetic result](README.md), all frozen sources, full rows and provenance remain unchanged. Three proposals remain K4-target-tested and 97 target-unrun; 72 canonical cipher-family records remain unchanged.

[Accepted C02 source/proof audit and static certificate](../c02-huffman-framing-audit-v1/README.md) retain the exact boundary proof, source comparison and remaining gates. This current note supersedes only the earlier recommendation to investigate M21 utility for C02; the original proposal-stage table is unchanged.
