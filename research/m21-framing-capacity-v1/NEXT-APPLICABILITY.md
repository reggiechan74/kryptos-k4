# Static applicability to catalog codec proposals

This is source/specification analysis, not another experiment or target admission. The original100-proposal catalog remains historical; use current status overrides. M21 is a validated method pilot, not a cipher family or a fourth K4 target test. Existing target-run counts must remain3tested/97unrun.

| Proposal | What M21 can potentially cover | Exact gap / recommendation |
|---|---|---|
| C02 fixed Huffman | Most direct fit: fixed single-letter bitword emissions, sentinel header1, no adaptive state. Exact fixed-width capacity is N<26^97, **not** minimal97-digit width. | Independently freeze actual tree and tie conventions, bound emitted lengths, prove decoder/framing equivalence, perform public equation-level deduplication. A separate synthetic adapter verification/state-cost assessment is needed before any target application. This is the preferred static next preparation, not permission to run. |
| C03 Tunstall | Finite phrase-trie state, bounded10-bit complete-phrase emissions; terminal trailer could implement the canonical A-completion. | Pilot fixture12 rejects incomplete phrases; it does **not** validate C03's distinct A-padding/trim contract. Freeze the1001-leaf dictionary, prove terminal completion/canonical inverse, and independently verify terminal behavior before transferring the theorem. |
| C01 arithmetic intervals | Integer range questions are related. | Catalog encoder uses exact rational nested intervals plus canonical representative selection, not the pilot's small finite-state bit-emission model. Need a separate proof/algorithm; do not wrap it in a nominal finite state whose size encodes the entire input. |
| C04 greedy LZ77 | Finite bounded message/history gives theoretical finiteness. | Window32 over26symbols and greedy future matching are not a small streaming encoder. Explicit history/lookahead-state bounds may be prohibitive. The current pilot does not establish tractability or validate the parser. |
| C05 generated grammar | Framing is in principle testable once fully specified. | Repair/tie order remains a specification gap; induced grammar state is not a bounded small automaton. No applicability promotion until exact serializer/state contract exists. |
| C06 numeral-state coding | Final integer range can be stated exactly. | Growing numeral state is not the pilot's small finite-state bit emitter. Need a separate bounded integer-state/counting argument and cost bound; do not claim M21 already covers ANS. |
| C07 occurrence-gap code | Gamma/Golomb subcomponents have bounded literal-code analogues. | Whole-input counts and progressively unassigned positions require global state, unlike local fixed symbol emissions. Specify a compact sufficient state or use a separate exact method; pilot table coverage is insufficient. |
| C08 language-path rank | Catalog has a small source-language DFA and exact completion counting. | The whole-word rank emission differs from per-letter finite bitword emission. Its fixed-width capacity is already immediate from rank<accepted-word-count<=26^97; M21 offers no new width rejection by merely relabeling that fact. Focus on ranking/inverse correctness if pursued, not redundant capacity work. |
| C09–C22 length-preserving combinatorial transforms | Output length is prescribed by construction rather than variable-bit framing. | Outside the useful scope of this capacity gate. Do not rerun already-tested C20 or claim M21 validates these transforms. |

The outer fixed-width AZ Vigenere layer in the catalog preserves digit count, but content equality and plaintext-position constraints remain a separate full relation. No phase search, actual97-symbol conversion, candidate fitting or new target calculation was performed for this table.

Recommendation: prepare an independently specified C02 adapter/state-size/prior-art review first; consider C03 only after proving its different terminal-completion contract. If neither establishes meaningful new coverage, retain M21 as infrastructure and move to another canonical hypothesis rather than inventing padded codec variants.
