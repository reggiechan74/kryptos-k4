# Study 061 findings

## Outcome

One approved production evaluation and one independent reference evaluation both returned **UNSAT_COMPLETE**: zero compatible cylinders for the 160 frozen structural settings. The canonical 97-letter input and 24 public clue letters were used at their unchanged positions. The all-zero key is prior-covered analytical territory and was not counted as new coverage. No model or gate changed after the target outcome.

This closes only the exact sum-conditioned right-rotation model with the two fixed alphabets, widths 3–12 and nominal periods 1–8. It is not a general impossibility result for nonlinear blocks, other checksums, other alphabets or added layers.

## Why this was eligible rather than a renamed old route test

Each observed ciphertext fixes one route for each alphabet/width pair. We compared those 20 full position maps, including inverse conventions, before solving target crib constraints. No map matched the inspected completed local catalogs or audited external families. The prior-key domain, alphabet roles, indexing, stage order and thresholds were reviewed separately; names alone were not used as evidence of distinctness.

Local checks cover ROUTE-001, ENE-ROUTE-049, HAND-GRAMMAR-050, occupied-cell and K3-clock routes, plus all possible ragged column orders at every width 2–96. Width 97 trivially admits every permutation, but was not established completed exhaustive prior coverage. The exact column-membership recognizer passes 192 planted positives.

Public comparisons cover Scott grid routes; dictionary/Myszkowski route necessary conditions; zeyeteam counter-rotations, cylinder routes, irregular/disrupted columns; grille necessary conditions; and EXT012's declared single/two-route composition universe. The largest membership passes include 16,151,520 disrupted-map descriptions and 12,936,000 grille-superset cases. These are preparation/duplicate-check counts, not cipher tests or global novelty evidence. Positive membership controls and CPU accounting are retained.

EXT012's unavailable old implementation commit does not justify an invented historical range: independent reconstruction matched its exact historical universe SHA256 `468923810eab9775145281e8e9a3eb470f4211589bfe691e2bdd249c58c2300a`, all 484 per-spec hashes and 250,348 declared configurations. The old executable's behavior remains unverified; its reported cryptanalytic outcome is not inherited.

## Exactness and identifiability

Rotation preserves block sum, so left rotation by the observed block's sum is an exact inverse. Once blocks are unrotated, each clue fixes one periodic-key residue. Conflict gives an empty set; otherwise unspecified residues vary independently. The generic engine returns that entire cylinder, never a guessed English completion. Nominal-period aliases and cylinder intersections are not double-counted as distinct operators or plaintext volume.

An independently authored scatter/gather implementation agrees with production's slice-based implementation. Each passes 19,656 tiny roundtrips and 137,268 complete solution-set comparisons against forward-generated truth. The target zero-key eligibility adapter passes 1,108 synthetic singleton tests, retaining nonzero constant keys and rejecting incomplete masks.

## Blind controls

A fresh post-freeze seed produced 320 full-mask plants, 32 sparse plants and 64 null controls. Both outputs were sealed before answers were inspected. All 416 complete sets agree, all 352 plants are included, all 320 full-mask plants recover uniquely, and all 32 sparse planted period-eight settings retain exactly seven free residues. No null control has any compatible setting. Literal-crib controls are random outside the clue mask; they do not test natural-English recovery.

Production used about 1.229 CPU seconds and reference about 1.583; analysis used 3.488. Independent benchmark audit used 6.596 seconds. External membership costs and missing-measurement reserves are separate in the resource ledger; early eligibility RSS was not measured and is not invented. No search-speed bottleneck emerged.
