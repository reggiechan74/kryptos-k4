# CSP889-SPARSE-015 — exact ownership and reserved predicate cache

Frozen after REAL-014 outcomes and before this implementation's benchmark outcomes, 23 October 2026. This is an engineering response to measured failures, not an independently discovered cipher family. No actual K4 evaluation.

Retain the exact two REAL-014 fixtures, all independent starts, reachable shared index quotient, continuous schedules, source wirings, collector, pulse and stepping conventions. Retain 60 seconds per fresh process, watchdog 65 seconds, 1-GiB measured RSS with 128-MiB headroom, conservative 256-MiB live target-domain envelope, and total 64-MiB predicate/translation cache. No fixture easing or larger budget.

Change only representation: each reachable index class has one deterministic trajectory for a fixed control start. Store sorted class ownership as integer-ID lists/tuples, not a high-position dense bitset per branch. At every step partition each owner's classes by the magnet mask computed from that SAME class's ten-digit map and the current continuous control digits. Merge only identical `(cipher offset, cipher-compatible domain)` keys; do not merge unequal cipher domains. Preserve aliases and full correlated relations. This holds before and after observations; no reset or guessed unknown plaintext is introduced. No class is silently dropped except when its associated cipher-start domain is empty.

Reserve 48 MiB for zero-offset/translated predicate values and at most 16 MiB for on-demand LRU coordinate-mask pairs. All cache counters and total accounted bytes are explicit. Eviction/disabling changes performance, not answers. The translation identity and bit indexing remain those proved in TORUS-013. Masks are computed exactly when absent. Cipher domains remain dense bitsets in this batch: a memory failure here is not a proof that compressed cipher domains are impossible.
