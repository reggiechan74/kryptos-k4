# H-EXAMPLE: stable descriptive title

Add the current entry to the canonical current register in research/HYPOTHESES.md.
Do not create a second status register or rename an existing ID. Preserve dated
historical entries and link the final scoped result when an older status changes.

- Status: untested / evidence-blocked / specified but not run / narrow negative / analytical exclusion / non-identifiable
- Mechanism: plain-language operation, distinct from motivation or a count coincidence.
- Evidence: separate cited public facts, supplied reviews, user hypotheses and creator-use evidence.
- Tested scope: exact model, domain, trial count or analytical certificate; include prior-art equivalence and negative results.
- Untested scope: what remains outside that finite conclusion; not a claim of worldwide novelty.
- Missing inputs: observations, provenance, conventions, keys or inverse/identifiability prerequisites.
- Next discriminating test: a bounded falsifiable next step, not an automatic parameter expansion.
- Dependencies: source gates and related stable hypothesis IDs; state what may not proceed yet.
- Results: linked experiment IDs, frozen specification, immutable outputs and exact limitations; say when no run exists.

For an executable pilot, also freeze alphabet/normalization/indexing, full inverse,
framing/state progression, fitted versus predicted observations, parameter and
runtime budgets, reference/planted/incompatible controls, matching null selection
when required, and success/rejection/ambiguity/timeout criteria in the existing
experiment ledger. A proof is not a brute-force run; a compatible fit is not a solution.
