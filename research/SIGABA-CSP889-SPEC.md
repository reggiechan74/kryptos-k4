# SIGABA-CSP889-001 — frozen before K4 evaluation

23 October 2026. This replaces no historical negative: the previous machine was explicitly custom. Implement CSP-889 / ECM Mark II using the pinned CrypTool conventions and data in `data/sigaba-csp889-v1.json`. Do not execute downloaded source. Validate all 12 published Sullivan-attributed vectors before K4. Validation against independent published outputs establishes agreement with that simulator convention; it is not hardware certification. CSP-2900 is outside scope.

Number physical wheels 1–10 (10 means table index 9), index wheels 1–5. Forward electrical path traverses cipher wheels left to right; inverse is reverse traversal. A normal rotor at position p maps x to W[x+p]−p modulo n. A physically reversed rotor maps x to p−W_inverse[p−x]. Its inverse swaps W and W_inverse. Normal wheel motion decrements position; reversed motion increments it. Index wheels use the same position/reflection convention and remain static. Cipher output precedes the step. Four control inputs F,G,H,I traverse the control bank right to left through its inverse electrical paths, the historical 26-to-10 collector, static index bank left to right, and magnet pairs 0/9,1/2,3/4,5/6,7/8. Selected cipher wheels step once. Control middle wheel steps each letter; if its PRE-step position is O, wheel 4 steps, and if wheel 4 is also at O, wheel 2 steps. Outer control wheels remain still.

## Bounded key domain

Two fixed wheel layouts: (cipher 10,1,2,3,4; control 9,8,7,6,5) from the published vectors, and (cipher 1,2,3,4,5; control 6,7,8,9,10) in numerical order. Index order always 1,2,3,4,5; all orientations normal. Cipher positions (c,c,c,c,c), control positions (A,A,q,A,A), index positions (r,r,r,r,r), c,q in A–Z, r in 0–9: exactly 13,520 raw key descriptions. These deliberately restricted weak/repeated starts have no Sanborn attribution. No key words, routes, normalization alternatives or adaptive expansion. Deduplicate complete 97-position schedules and actual full outputs separately.

Fit nothing: continuously propagate from position 1 through unknown gaps. Check the 13 first disclosed letters at positions 22–34, then only surviving keys against positions 64–74. No crib-boundary reset. Retain every compatible key and full plaintext; regenerate all 97 symbols for any survivor. Empty first-stage set gives an exact finite negative, not an exhaustive SIGABA exclusion. Raw machine framing is A–Z; historical space→Z and Z→X operator conventions are not silently applied to K4.

## Controls and stopping

All 12 external vectors both directions; complete per-wheel, per-position, per-symbol inverse checks including reversed orientations; independent signed-coordinate electrical-path oracle; 805-letter state comparison against a separately expressed control-counter oracle; unrelated text roundtrips. Four 97-letter plants with the actual literal crib strings/positions, both layouts and edge starts, through the entire selector: retain truth and all ambiguous keys. A constant-ciphertext incompatible control and mutated-vector rejection. Freeze first, then controls, then actual K4. Runtime budget 180 seconds per selector, 512 MB estimated memory ceiling; stop as budget-unresolved rather than exclude an uncompleted domain. No significance simulation unless a complete survivor motivates a separately specified matched null.
