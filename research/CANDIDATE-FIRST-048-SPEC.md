# Candidate-first 048 — protocol for parent audit before a full candidate run

Local only. This is a new bounded test inside families 1/7, not an answer oracle. Prior photo follow-through is complete at 57671 d 8. The protocol is frozen before new key-source preflight or candidate evaluation. Existing 044 period/lag results are known design inputs, not blind predictions.

## Representation and frozen cipher/key families

Canonical ciphertext remains 97 A–Z letters; plaintext must be exactly 97 normalized letters with EASTNORTHEAST at one-based 22–34 and BERLINCLOCK 64–74. No spelling repair, route, padding, dropped character, crib relocation, source-alphabet permutation or full-length free key. Do not impose word boundaries from these clues.

Use two explicit alphabets: AZ=`ABCDEFGHIJKLMNOPQRSTUVWXYZ`; KRYPTOS=`KRYPTOSABCDEFGHIJLMNQUVWXZ`. Three equations modulo 26: C=P+K, C=P−K, C=K−P. Four stream constructors: periodic key, plaintext autokey, ciphertext autokey, and non-repeating running key. Periods/primer lengths 1–32 inclusive; running key length 97. Phase 0 at message position 1. This is 6×(32×3+1)=582 model descriptions, not 582 independent keys. The definitions are standard classical possibilities; neither Sanborn nor the themes select these models. Existing exact crib contradictions remain binding. KRYPTOS keyed coordinates do not supply an unknown keyword.

Source key material is chosen independently: the existing hash-pinned Brown 500-document 1961 print corpus snapshot, official nltk/nltk_data commit `18fcb5421e3d590673282ee5c1624facf960b52c`, packages/corpora/brown.zip, SHA-256 `9b275f9b3b95d7bd66ccfb7cd259f445a13bbe5d1f4107aba09fd3e8364bafa6`. It has already been inspected in 033–045 and is not pristine validation or a creator-selected book. No new source is added after results.

For each source document, remove POS suffixes after the last slash in each token, uppercase and retain A–Z; concatenate in source order across its sentences, never across documents. A source key must be an **exact contiguous normalized passage**, including any character start: length L for a repeated key/primer, or 97 for a running key. No anagram, approximate-English score, arbitrary rotation, reversal, leetspeak, header stripping or post-hoc source hunt. A phase shift is outside this frozen model. Repeated occurrences are provenance aliases, not independent keys. Keyword-like spelling alone is not acceptance. Brown is an exploratory independent source bank, not historical evidence of the actual key.

## Required preflight before generating the bank

First independently derive all 24 crib constraints and exact conflict witnesses per 582 descriptions, cross-checking prior 044 profiles where applicable. Record longest fixed key/primer substring and every remaining free parameter. Then exhaustively test admitted source passages for compatible keys, using exact substring anchors only as lossless indexing: every full mask/chain must still be checked. A derived arbitrary key is never admitted. This preflight does not need guessed plaintext. If no registered key survives, no candidate can rescue these exact models; report that narrow result and do not manufacture 1000 irrelevant messages. A surviving unconstrained long key is not enough: its exact source membership is mandatory.

Before actual K4 preflight, run independent forward/inverse/reference controls and 24 synthetic 97-letter plants (four constructors × two alphabets × three equations), with source keys selected deterministically from the frozen corpus, period/lag 5 for the three seeded constructors, and 97 for a running key. Synthetic plaintexts carry the same two literal crib windows; their remaining 73 letters are hidden truth for recovery checks, not claimed English. The actual acceptance/source lookup pipeline must retain the true keys and regenerate all 97 cipher letters, without claiming uniqueness when other source keys remain admissible. Compact exact source-position relations are permitted for unconstrained domains; silently sampling them is not. Compare complete tiny candidate/key relations to brute force. No plant-dependent adjustment of source membership, masks or candidate wording.

## Conditional 1000-message bank: construction and provenance

If at least one **source-admissible** registered key survives, freeze a bank before candidate/key scoring. The available honest generation method is **model-authored clause banks followed by combinatorial assembly**, not 1000 independently model-written complete messages: ten 21-letter prefixes × ten 29-letter middle clauses × ten 23-letter suffixes, surrounding the two fixed 13/11-letter windows, gives 1000 normalized 97-letter messages. All boundaries, displayed spaces/punctuation, clauses and assembly rules must be saved/hash-pinned before scoring. Clauses must fit one shared grammatical template; no padding, clipped words or random filler. Check all 1000 distinct normalized strings and review the template/readability failures explicitly. If ten admissible clauses per bank cannot be authored, report the actual count/limitation; do not relabel duplicates or ungrammatical assemblies. Combinations share clauses and are not independent guesses.

Use only primary-supported themes forwarded by the parent as soft generation priors: Egypt trip, Berlin Wall/World Clock and message delivery. Preserve the 1988 writing/Wall-fall chronology inconsistency in the source; do not invent a trip/date or treat a theme as a plaintext fact. The full source distinctions are supplied in the provenance caveat below and remain priors rather than hard facts. Generic invented candidate details must be marked speculation. Neither forced crib phrase supplies independent support for a candidate.

For each bank message derive the exact key/primer for every admitted model, require all stream consistency and source-membership conditions, independently decrypt and re-encrypt all 97 letters, and preserve every accepted ambiguity. Report distinct messages, source keys, model descriptions and provenance aliases separately. Actual unknown 73 positions have no independent ground truth: full re-encryption is necessary but a freely derived-key round trip is tautological. No actual blind held-out plaintext claim; synthetic held-out 73-letter recovery is checked separately.

## Controls, multiplicity and stopping

Before a full bank, run 31 fixed-seed whole-pipeline null preflights by permuting only the 73 unanchored ciphertext positions, preserving the 24 anchored cipher entries. If a bank is reached, additionally permute the 73 unanchored plaintext letters of each bank message with a separate fixed seed and rerun all 582 models/source tests. Preserve crib positions and character histograms. Run exactly the same complete acceptance rule and report family-wide accept counts/maxima; no partial-score promotion or uncorrected best-of-bank probability. These are conditional permutation diagnostics with an exchangeability assumption, not a universal chance model, especially for dependent thematic assemblies and reused Brown data. Resolution is at best 1/32; absence of null hits neither proves a solution nor validates a universal probability.

Budgets:180 seconds/1 GiB for source ingestion and controls,180 seconds/1 GiB for actual plus 31 null preflight,600 seconds/1 GiB for a conditional 1000-message bank and matched nulls. Timed-out domains remain unresolved; do not silently sample or extend budgets. Freeze seeds 48001/48002. Save UTC start/end, hashes, complete masks/counts/accepted cases and source coordinates; raw Brown text stays outside the repo. No external model call, new credential, paid Paradigm submission, personal-data transmission, push or Site change.

**Audit gate:** return this specification and the two queued finite specifications to the parent before any full bank or large route/grammar search. Preflight/controls may proceed independently after the design checkpoint; do not claim a full batch has run.
