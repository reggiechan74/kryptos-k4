# Public packaging policy

This is a pretarget evidence package, **NON_RELAUNCH_READY**. It is neither an executable source freeze nor a grant, acceptance token, target result or terminal seal. No command in a historical document is authorized for use by this package.

Mathematical and operational `.py` sources and the four disclosed fixture files are byte-exact copies. Embedded original generic host paths in those sources are intentionally retained to preserve their original hashes; they are provenance, not a portable deployment configuration. The original mathematical caps file is also copied exactly.

Administrative documents are explicitly marked public derivatives. Full planning, admission, search, protocol and README texts are retained; only administrative identity/path material is sanitized. JSON wrappers retain historical values and original scientific commitments but cannot be consumed as the original authority schemas. Historical hashes inside a derivative remain **original-file commitments**, not checksums of the public derivative; use PROVENANCE.json for the original-to-public mapping.

Sanitization removes private responsibility-page versions, task/agent references, private administrative URLs, execution-session/chunk identifiers, tool-completion coordination fields, process IDs and executable approval references. Public source citations, scientific semantics, status/counter/resource values, failure history, exclusions, uncertainty, scope limits and stop rules remain. Each mapping identifies the exact changed fields or text rules. The current status is stated separately in STATUS.json and does not rewrite historical records.

The package builder does not read the canonical K4 input and does not read, hash, copy, archive or extract any certificate. The separate certificate owner alone supplies the permitted archive and CERTIFICATE-PROVENANCE.json. No private historical authority, seed or truth files are read or included. No scientific or operational source is imported or executed during packaging.
