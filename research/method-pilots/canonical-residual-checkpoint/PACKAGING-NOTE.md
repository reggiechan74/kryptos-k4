# Publication preparation — not scientific execution

This package is a new sanitized evidence derivative. All scientific originals,
including failed and superseded records, remain untouched. Preparation read only
the explicit source roots in `SOURCE-INVENTORY.json`. For the failed cohort it
read **only** the already-approved incomplete release and supplement, never the
original custody/seed/truth directories. The generic CPU diagnostic is included
from the approved release's existing copy. No scientific module was imported,
compiled or executed, and no next-pilot trace was expanded.

## Transformations and integrity

- Workspace, scratch, runtime and home path prefixes become inert archive labels.
  Role identifiers and private administrative references become generic labels.
- Private handoffs, bytecode caches and an unfrozen working draft are excluded.
- One retained administrative acknowledgment/stop receipt has three private
  coordination strings paraphrased into public scope statements; its numerical
  and status fields, lack of terminal acknowledgment and false truth-release
  authorization remain unchanged. Its original hash is retained.
- All other changes are explicit literal/regular-expression string or comment
  substitutions. Public `PROVENANCE.json` binds every selected source hash and
  size to every public path/hash/size and its applied rule counts.
- Python non-string/non-comment token streams are unchanged across all 75 source
  files. This verifies computational tokens, not arbitrary string semantics;
  path strings deliberately differ; all 34 changed string tokens in 18 files
  are listed in `PYTHON-STRING-CHANGES.json` for separate static review. The 632
  other JSON/JSONL files preserve nonstring lexical content; the noted scope
  receipt is checked structurally after its formatting change; parsed JSON structure
  and nonstring values are unchanged with only path-valued keys normalized.
- This does not reissue original source pins or make the archive executable in a
  new environment. Existing scientific freezes authenticate original bytes;
  the new package manifest authenticates public derivatives.

The two 33,554,433-byte oversize I/O mocks and numerous empty mocked logs remain
included and labeled by their historical operational-test directories. They are
not additional cohort jobs, independent mathematical inputs or scientific runs.
Repeated source/results in historical snapshots are preserved copies, not extra
resource usage to add again.

## Retained preparation correction

The first local packaging attempt stopped when a structural guard compared
path-valued JSON object keys before applying the documented path normalization.
It detected an expected metadata-key transformation, not a changed number or
scientific result. The incomplete packaging tree and original packager script
were preserved outside this release. The comparator was corrected to normalize
those keys before comparing structure; a fresh package build passed. A later
pre-release sanitation refinement covered a root-only path and additional
administrative wording. These were **packaging-only attempts**, not scientific
failures, solver reruns, fresh draws or source fixes. No incomplete packaging
tree is part of the public evidence manifest.

Scoped CPU for the first successful preparation pass was 20.596485283 seconds;
the final preparation pass was 25.895069999 seconds. The initial stopped attempt
has no dedicated CPU receipt. The final integrity/archive pass is separately
recorded in the release receipt. Shell/tool activity, static inspection, report
writing, startup/exit tails and review are not fully metered. These are additional
publication-preparation observations, not a fully measured project total and not
permission to replenish an experimental allowance. Original scientific resource
ledgers and allocations are unchanged; next-stage contingency remains unused.
